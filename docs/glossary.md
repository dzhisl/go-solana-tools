# Glossary

| Term | Meaning |
| --- | --- |
| Lamports | Integer SOL units; 1 SOL is 1,000,000,000 lamports. |
| Raw amount | Integer token amount before decimal scaling. |
| UI amount | Exact decimal string calculated from raw amount and decimals. |
| Mint | Token definition account, containing supply and decimals. |
| Token account | Account storing a balance for a mint and a wallet owner. |
| ATA | Deterministic associated token account for wallet, mint and token program. |
| Account program | Program owning a Solana account; different from its token wallet owner. |
| Commitment | Consistency level requested for RPC reads. |
| ALT | Address lookup table used in versioned transaction messages. |
